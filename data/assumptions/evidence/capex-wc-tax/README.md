# Лист «capex, оборотный капитал, касса, аренда, налог» (область capex-wc-tax)

Доказательный лист книги допущений X5, 28.09.2026 (правки аудита раунда 3 — книга 1.1.2, 29.09.2026). Суждения: A-K1…A-K7 и A-P3 (capex),
A-W1…A-W4 (оборотный капитал, касса, аренда), A-T1…A-T2 (налог), предложение A-F3b
(`financing.cash_buffer_pct`). Семантика ключей — `docs/MODEL.md` §4.5–§4.8, §6. Текст разделов —
`data/assumptions/ASSUMPTIONS-BOOK.md`, разделы 4–8; машинный фрагмент — выход листа `fragment.yaml` (значения =
выходам скриптов = `assumptions.yaml`, сверяет `check_fragment.py`).

## Как перезапустить

```
python -B capex.py            # A-K1…A-K7, A-P3 → capex_out.txt / capex_out.json
python -B wc_cash_lease.py    # A-W1…A-W4, подушка кассы → wc_cash_lease_out.*
python -B tax.py              # A-T1, A-T2 → tax_out.*
python -B check_fragment.py   # фрагмент = выходы листа = книга (assumptions.yaml); PyYAML
python -B build_inputs.py [--handoff ../x5-850-handoff]   # пересборка inputs/ (факты X1, databook, ИПЦ, снимок книги)
python -B build_inputs.py --book-refs                      # только снимок итоговой книги inputs/book_refs.json
```

Расчёты — Python 3.11+ (только стандартная библиотека), читают только `inputs/`; вывод детерминирован
и побайтно одинаков на Windows и Linux (перевод строки `\n`). `build_inputs.py` нужен лишь для
пересборки входов: он читает факты исследования X1 (`research/facts/*.json`), старый databook
(capex 2011–2017), databook 2К2026 (строки ОДДС о выбытии и прочих инвестиционных платежах), месячный ИПЦ
Росстата (нужен `openpyxl`) и итоговую книгу `data/assumptions/assumptions.yaml` (нужен PyYAML).

## 1. Сеть: валовое открытие площади (`capex.py`, раздел 2)

Databook даёт только остатки площади; открытия «без учёта закрытий» и закрытия — в торговых релизах (поквартально).
Валовое открытие площади = чистый прирост + закрытые магазины × средняя площадь магазина формата на начало периода.
Закрытия «Пятёрочки» и «Перекрёстка» = все открытия «без учёта закрытий» минус чистый прирост магазинов; у «Пятёрочки» это
«добавив N новых магазинов», а не открытые «в современной концепции» (440 и 420 в 1 кв. 2025 г.; с 4 кв. 2025 г. раскрыто
только второе число). «Чижик» — чистый прирост плюс раскрытые закрытия: 1 / 2 / 3 во 2–4 кв. 2024 г., 4 / 5 / 4 в 1–3 кв.
2025 г., дальше раскрыт только чистый прирост. Так же закрытия считают факты (`data/facts/network.json`) и лист сети, по
которому откалибрована доля закрытий книги (`network.close_rate`): ядро умножает цену открытия на валовое открытие в этом
базисе, и полугодия 2025 г. листа совпадают с фактами (`network.gross_opened_hist`, `closed_area_est`). Базис «Пятёрочки»:
2024 — как отчитано (без «Красного Яра» и «Слаты», как и открытия бренда), с 2025 — с ними.

якоря), 2,92 % (раздел 8, ниже «Пути»).

«Прочие платежи нетто» — прочие платежи по инвестиционной деятельности (ОДДС стр. 42) минус тело чистых инвестиций
в аренду (стр. 41), раздел 1б `capex.py`: 0,21 / 3,18 / 8,42 / 4,23 против 0,05 / 0,23 / 0,49 / 0,64 млрд ₽ (2023 / 2024 /
2025 / 1П2026), нетто 0,08 / 0,17 / 0,14 % выручки (2024 / 2025 / 1П2026), 0,20 % за LTM. Решение книги (A-K1): поток
капитального характера — возвращается только тело финансовой аренды франчайзи (стр. 41, вычтено; недисконтированные
платежи по ней — 0,98 млрд ₽ на 31.12.2025), займов третьим лицам в примечании о кредитном риске нет, других
поступлений в ОДДС нет, прочие внеоборотные активы выросли за 2024–1П2026 на 6,4 млрд ₽ при оттоке 14,5 нетто;
компания включает строку в скорректированный отток по инвестиционной деятельности (224,7 млрд ₽ за 2025 г.).

Остаток «поддерживающий» тяжелее в 1-м полугодии (доля в выручке полугодия к году: 1,05 / 0,95 в
2024 г., 1,01 / 0,99 в 2025 г.) — реконструкции X5 идут весной, открытия — осенью.

## 5. A-K1. Поддерживающий capex снизу вверх (`capex.py`, раздел 7)

Стационар при нулевом чистом росте, цены и площадь якоря, выручка якоря LTM 4 878,6 млрд ₽ (так ядро считает
физическую часть: φ × mnt × выручка якоря — годовые рубли в площади 30.06.2026 и ценах якоря, MODEL §4.5); метод один
для трёх уровней.

1. **Магазины (физическая статья).** Статья «поддержание магазинов и реконструкции» 2025 г. — 56,0 млрд ₽
   при 1 075 реконструкциях «Пятёрочки», 27 полных и 40 рестайлингах «Перекрёстка» (462 тыс. м²-экв.) —
   переводится в цены якоря и на площадь 30.06.2026 (62,3 млрд ₽), затем добавляется разница между
   стационарным и фактическим числом реконструкций × удельная стоимость. Стационар реконструкций =
   (1 / цикл − доля закрытий книги 2 %) × площадь (закрытые и заменённые магазины реконструкцию не
   проходят — их оплачивают замещающие открытия A-K3); «Чижик» — с весом ½ (дискаунтер дешевле).
   Удельная стоимость: низ 19,6 тыс. ₽/м² (минимум 2015 г. — 5 косметика + 5 оборудование, × ИПЦ 1,957),
   верх 43,4 (отношение «редизайн / новый магазин» Магнита 38/48 × 54,8), центр 31,5 (≈12,2 млн ₽ на
   средний магазин «Пятёрочки» 386 м²).
2. **Автопарк (доля выручки):** 7 465 ед. × 15,8 млн ₽ / срок замены 10 / 8 / 7 лет.
3. **РЦ и логистическая инфраструктура (физическая):** 0,12 / 0,18 / 0,25 % выручки.
4. **IT и проекты эффективности (доля выручки):** 0,45 / 0,55 / 0,65 % (статья 2024 г. — 0,47 %,
   2025 г. — 0,65 %; поступления ПО — 0,45 / 0,59 / 0,68 % в 2024 / 2025 / 1П2026).
5. **CVP, готовая еда, онлайн — замена оборудования (физическая):** 0,10 / 0,15 / 0,22 % (статья 2025 г.
