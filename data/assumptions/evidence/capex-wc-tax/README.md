# Лист «capex, оборотный капитал, касса, аренда, налог» (область capex-wc-tax)

Доказательный лист книги допущений X5, 28.09.2026. Суждения: A-K1…A-K7 и A-P3 (capex),
A-W1…A-W4 (оборотный капитал, касса, аренда), A-T1…A-T2 (налог), предложение A-F3b
(`financing.cash_buffer_pct`). Семантика ключей — `docs/MODEL.md` §4.5–§4.8, §6. Текст раздела —
`data/assumptions/sections/capex-wc-tax.md`, машинный фрагмент — `data/assumptions/fragments/capex-wc-tax.yaml`.

## Как перезапустить

```
python -B capex.py            # A-K1…A-K7, A-P3 → capex_out.txt / capex_out.json
python -B wc_cash_lease.py    # A-W1…A-W4, подушка кассы → wc_cash_lease_out.*
python -B tax.py              # A-T1, A-T2 → tax_out.*
python -B build_inputs.py --handoff <x5-850-handoff>   # только пересборка inputs/ из фактов X1
```

Расчёты — Python 3.11+ (только стандартная библиотека), читают только `inputs/`; вывод детерминирован
и побайтно одинаков на Windows и Linux (перевод строки `\n`). `build_inputs.py` нужен лишь для
пересборки входов: он читает факты исследования X1 (`research/facts/*.json`), старый databook
(capex 2011–2017) и месячный ИПЦ Росстата (нужен `openpyxl`).

## 1. Сеть: валовое открытие площади (`capex.py`, раздел 2)

Databook даёт только остатки площади; валовые открытия и закрытия «Пятёрочки» и «Перекрёстка» —
в торговых релизах (поквартально, «on a gross basis»). Валовое открытие площади = чистый прирост +
закрытые магазины × средняя площадь магазина формата на начало периода; «Чижик» — закрытия не
раскрыты и приняты нулевыми. Базис «Пятёрочки»: 2024 — как отчитано (без «Красного Яра» и «Слаты»,
как и валовые открытия бренда), с 2025 — с ними.

## 9. A-W1. Оборотный капитал (`wc_cash_lease.py`, разделы 1–4)

Определение книги — **всё, что проходит через операционный поток** (NWC_op): запасы + торговая и
прочая дебиторка с авансами + НДС и прочие налоги к возмещению − торговая кредиторка − обязательства
по договорам − операционная часть «Резервов и прочих обязательств» (прочая кредиторка и начисления,

полученные, прочие нефинансовые). Не входят: дивиденды к выплате, кредиторка за ОС/НМА/бизнесы

обработке» (МСФО 2024, прим. 9). Операционная касса = D1 в среднем 0,80 % + минимальный остаток

1,51 % → **подушка 0,45 %** выручки (неиспользованные линии 772,6 млрд ₽ на 31.12.2025).

## 11. A-W4. Аренда (`wc_cash_lease.py`, раздел 6)
