## Как перезапустить

Python 3.11+. Анализ — стандартная библиотека; `model_check.py` и `check_fragment.py` берут ещё PyYAML и код ядра
репозитория (`model/`). Сеть не нужна. Порядок:

```
python -B extract_inputs.py      # только при пересборке входов: папка передачи x5-850-handoff, magnit-850oa, openpyxl
python -B rates.py               # (1) доля фикса, «старый» фикс, спреды, касса        → rates_out.json
python -B leverage.py            # (2) целевой рычаг, начало выплат, предел рычага     → leverage_out.json
python -B bridge.py              # (3) строки моста                                    → bridge_out.json
python -B valuation.py           # (4)–(5) β_u, ERP, дисконт за управление, печать      → valuation_out.json
python -B model_check.py         # (7) ядро на книге assumptions.yaml (≈5 с)          → model_check_out.json
python -B gates.py               # (6) коридоры гейтов и их массы (читает model_check_out.json — после него) → gates_out.json
python -B band_check.py          # полоса §9 и обратный DCF §11 на той же книге (≈3 мин)  → band_check_out.json
python ../../../../ops/tools/check_worlds.py   # миры книги = миры книги Магнита на теге (нужен ../magnit-850oa)
python -B check_fragment.py      # фрагмент = выходы листа; оси других областей; черновик + фрагменты = книга; схема
```

Консольный вывод каждого скрипта — рядом (`*.out`).

## 4–5. Оценка — `valuation.py`

**β_u.** Лист беты книги Магнита 1.4 (по 18.09.2026, X5, недели, полная доходность к MCFTR, Харрис — Пингл, β_d 0,1):
2 года (только акция) — β_E 0,683 → **0,514** (95 %: 0,43–0,60); **3 года — 0,789 → 0,601** (0,48–0,73); 5 лет — 0,892 → 0,651
(0,54–0,76); до 2022 — 0,478. Лист X4 по 25.09.2026: окно одной акции 0,512; с поправкой Блюма — 0,586. Собственные β_u
аналогов: Магнит 0,45 / 0,57 / 0,66, Лента 0,30 / 0,38 / 0,50 (2 / 3 / 5 лет). Книга Магнита: 0,70 = 0,601 × 1,158 (операционный
рычаг Магнита). **Книга:** 0,60 (то же окно 3 года — одна измерительная база двух панелей), ось 0,45–0,75.

**ERP.** Damodaran 05.01.2026: Россия — дефолтный спред 2,56 %, страновая премия 3,90 %, ERP 8,13 %; зрелая 4,23 %. Центр
**5,57 %** = 8,13 − 2,56 (как у Магнита). Верх Магнита 6,14 % — λ-конвенция (λ = 1) при β 0,70: (0,70·4,23 + 3,90 − 2,56)/0,70 —
воспроизводится. То же правило при β X5 0,60: (0,60·4,23 + 1,34)/0,60 = **6,46 %** → ось **4,9–6,5 %** (низ — реализованная
премия с 2003 г., общий). Премия β_u × ERP = **3,34 п.п.** (у Магнита 3,90); по концам β — 2,51–4,18; обе оси — 2,21–4,88.

**Казначейский пакет и дисконт за управление.** Пакет 25,592 млн акций = 9,42 % выпущенных (N + n = 271,573 млн); одобрен к
отчуждению до 3 лет. Продажа n акций по P_s даёт акционеру (E + n·P_s)/(N + n) на акцию: размывание к стоимости акции V —
n/(N + n)·(1 − P_s/V), нейтральна продажа по стоимости, а не по рынку. Книга 1.0 мерила дисконт продажи к VWAP (0,0942·d =
0,83 % в g), то есть молча брала V = рынку при V модели ≈ 2× рынка. Книга 1.1: пакет — в формуле цены (MODEL §7.2):
цена = [(V0 − D) + n·k·P_рынок/1000]·(1 − g)·1000/(N + n). Факт 1П2026: 0,861 млн по 2 334,5 ₽ при VWAP 1П2026 2 453,4 ₽
(−4,8 %; к 2К −1,4 %, к 1К −7,3 %). Сценарии: рынку и инвесторам 0,8 × 0,952 + M&A по рынку 0,1 × 1 + нераскрытому кругу за

## Что проверяет `check_fragment.py`

Ключи фрагмента — только область; каждое число фрагмента = выход скрипта листа; веса миров, λ, оси весов и инфляции M = книге
Магнита; итоговые оси покрывают предложения фрагментов margin, capex-wc-tax, network-revenue (`../<область>/fragment.yaml`) и
все оси черновика; книга `assumptions.yaml` проходит `validate_book`, а черновик + все фрагменты листов совпадают с ней по
значениям (кроме `meta`; траектории — по всем прогнозным полугодиям и LT, форма записи свободна). Книгу прогона
`model_check.py` и `band_check.py` берут из `book_merge.build_book()` — это канон `assumptions.yaml`; сборка «черновик +
фрагменты» (`book_merge.merged_book()`) нужна только этой сверке.
