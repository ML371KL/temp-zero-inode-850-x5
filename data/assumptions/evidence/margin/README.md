28.09.2026. Ключи книги: `margin.targets` (4 режима, якорь 2026H1…LT), `joint.regime_prob`, `joint.regime_demand`,
`margin.deviation_persistence` (единственный ключ ρ — и хвоста якоря, и правила A-P2u), `margin.seasonal_h1_pp`,
`margin.lti_pct`, `joint.regime_update` (`sigma_pp`, `cap_pp`, `observations`), `valuation.next_report` (`period`,
`demo_values`). Семантика — `docs/MODEL.md` §3, §4.3,
§4.4, §10, §12. Маржа — скорр. EBITDA до МСФО 16 **без LTI** (так X5 раскрывает её и так дан прогноз «6+ %»);
LTI — отдельная строка. Фрагмент книги — выход листа `fragment.yaml` (значения = выходам скриптов = `assumptions.yaml`);
текст раздела — `../../ASSUMPTIONS-BOOK.md`, раздел 3.

## Как перезапустить

Python 3.11+, стандартная библиотека (+ PyYAML только для `check_fragment.py`). Сеть не нужна. Порядок:

```
python -B extract_inputs.py      # только при пересборке входов: нужна папка передачи x5-850-handoff и magnit-850oa
python -B series.py --sim        # (3) σ, ρ, сезонность, уровень на якоре      → series_out.json
python -B refclass.py            # (1) цели LT и вероятности                  → refclass_out.json
python -B paths.py               # (2) ближние траектории, прогноз «6+ %»      → paths_out.json
python -B ap2u_history.py        # (2) правило A-P2u на истории 2019–2026     → ap2u_out.json
python -B lti.py                 # (4) LTI                                     → lti_out.json
python -B next_report.py         # (5) «что даст отчёт» 2П2026                → next_report_out.json
python -B check_fragment.py      # фрагмент = выходы листа = книга (assumptions.yaml), схема = черновик
```

Консольный вывод каждого скрипта сохранён рядом (`*.out`). Без флага `--sim` `series.py` не считает смещение оценки ρ.

**Модель ряда** — та же, что у книги (MODEL §4.3): маржа = уровень режима + сезон + отклонение AR(1). Уровень в истории
неизвестен и оценивается вместе с отклонением: уровень — случайное блуждание с шагом q за полугодие, отклонение — AR(1)
(ρ, стационарное σ). Максимум правдоподобия фильтра Калмана на сетке; интервалы — профиль правдоподобия (95 %).

| Вариант | ρ (95 %) | σ отклонения, п.п. | q уровня, п.п./полуг. |
|---|---|---|---|
| **2011H1–2026H1, сезон 0** | **−0,35** (−0,80…+0,15) | **0,42** (0,28–0,60) | **0,22** |
| сезон свободен | −0,30; сезон s = +0,10 (−0,15…+0,30), прирост ll 0,29 | 0,40 | 0,22 |
| 2017H1–2026H1 (окно листа Магнита) | −0,45 (−0,90…+0,25) | 0,52 | 0,26 |
| 2022H1–2022H2 заменены | −0,35 (−0,75…+0,20) | 0,34 | 0,22 |

- **Проверка без фильтра** — автокорреляция 1-го порядка отклонения от центрированного скользящего среднего 5 / 7
  полугодий: −0,32 / −0,40 (sd отклонения 0,43 / 0,48 п.п.). Статистика смещена к минусу по построению (у белого шума
  −0,30 / −0,19): на рядах модели первой строки (5 000 рядов) её ожидание при ρ = 0 — −0,25 / −0,12 (P(≤ наблюдённой)
  0,32 / 0,06), при ρ = −0,35 — −0,40 / −0,33; откалиброванная оценка ρ — −0,14 / −0,45. Отрицательному ρ не противоречит,
  отдельным доводом не служит.
- **ρ Магнита (+0,7) историей X5 отвергается**: падение логарифма правдоподобия −5,40 (χ² = 10,8, p ≈ 0,001); на окне
  2017–2026 −3,68 (p ≈ 0,007). Отклонение X5 не «тянется», а **перекладывается между полугодиями**: слабое 1П — сильнее
  2П (2025: 5,80 → 6,48; 2019–2021 и 2022 — наоборот). Это и есть «держит пол вторым полугодием».
- **Смещение оценки** (симуляция, 40 рядов той же длины при σ и q первой строки): истинное ρ −0,35 → средняя оценка −0,36;
  ρ 0 → −0,05; ρ +0,3 → +0,26. Оценка −0,35 практически несмещённая.
- **Сезонность**: 2П − 1П за 2011–2025 — среднее −0,24, медиана +0,13, sd 0,83, t = −1,13; по эпохам +0,32 (2011–2016),
  −0,78 (2017–2024), 0,00 (2023–2025). Знак менялся дважды; свободный сезон не значим (прирост ll 0,29).
- **Уровень на якоре 2026H1** (фильтр при оценках первой строки): **6,072 %** (± 0,23), LTM 2К2026 — 6,083 %;
  отклонение якоря −0,374 п.п. Путь уровня: 2024H1 6,98 → 2024H2 6,65 → 2025H1 6,24 → 2025H2 6,28 → 2026H1 6,07.
- **σ правила A-P2u.** Путь режима в книге детерминирован, а реальный уровень внутри режима блуждает, поэтому дисперсия
  шага прогноза при известном уровне = σ²(1 − ρ²) + q² = 0,451² п.п.²; σ правила (стационарная, как в MODEL §10) =
  0,451 / √(1 − 0,1225) = **0,48 п.п.** (чистое AR(1) без блуждания — 0,42).
