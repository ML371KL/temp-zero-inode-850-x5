# Лист «Сеть и выручка» (область network-revenue) — книга X5 1.1.3

28.09.2026. Ключи книги: `network.net_growth` (тарифы low/mid/high), `network.close_rate`, `network.maturity_curve`,
`network.new_space_density`, `network.closed_productivity`; `revenue.ticket_k`, `revenue.ticket_shift`,
`revenue.traffic` (состояния спроса bear/base/bull), `revenue.other_growth`, `revenue.vat_effect`,
`revenue.homogeneity`; предложение по `joint.world_links[*].growth` и `joint.stress_growth`. Семантика — `docs/MODEL.md`
§3, §4.1, §4.2, §6. Фрагмент — выход листа `fragment.yaml` (значения = выходам скриптов = `assumptions.yaml`); текст
раздела — `../../ASSUMPTIONS-BOOK.md`, раздел 2.

**Главное.** LFL книги (чек и трафик) — это LFL **зрелой сети**: X5 включает магазин в LFL со всей выручкой с даты
открытия, поэтому отчётный LFL содержит созревание магазинов второго года, а ядро держит созревание в эффективной
площади (§4.1). Отчётный LFL выше книжного на m ≈ 1,4 п.п. (2П2026) → 0,9 п.п. (2028) → 0,27 п.п. (терминал).

## Как перезапустить

Python 3.11+, стандартная библиотека; PyYAML и пакет `model/` репозитория — только для `check_2026h2.py`,
`valuation_effect.py`, `check_fragment.py`. Сеть не нужна. Порядок:

```
python -B extract_inputs.py    # только при пересборке входов: нужна папка передачи x5-850-handoff
python -B vat.py               # (5) клин НДС 22 %                              → vat_out.*
python -B network.py           # (1)(2) тарифы чистого роста, закрытия             → network_out.*
python -B density.py           # (3) созревание, d, κ, m                           → density_out.*
python -B ticket.py            # (4) k, сдвиг чека, трафик по состояниям спроса    → ticket_out.*
python -B other.py             # (6) прочая выручка                                → other_out.*
python -B check_2026h2.py      # сквозная проверка выручки 2П2026 ядром            → check_2026h2_out.*
python -B valuation_effect.py  # цена ошибки суждений (точка ядра, справка)        → valuation_effect_out.*
python -B check_fragment.py    # фрагмент = выходы листа = книга (assumptions.yaml); книга проходит схему ядра
```

Каждый скрипт печатает лист и пишет его в `*_out.txt` (текст) и `*_out.json` (числа); перевод строки `\n` на любой ОС.

## 5. НДС 22 % — `vat.py`

при 22 % скачок +0,70 % — совпадает. Книга: `vat_effect` 2П2026 = 1/1,00723 − 1 = **−0,72 %**, с 2027 г. — 0 (`LT: 0`).
В черновике ключ без `LT` читался как −0,6 п.п. навсегда (MODEL §0.1, п. 4) — ошибка черновика.

## Ограничения

* Форма кривой созревания не различима по отчётности (RMSE 0,60–0,66 п.п. у всех вариантов); выбор сдвигает d и m
  вместе, выручка ближнего периода от него почти не зависит, терминал — через (d − κ).
* κ не раскрыт; в подборе d он связан с d (d* 0,79 / 0,83 / 0,87 при κ 0,4 / 0,6 / 0,8).
* Валовые открытия «Чижика» с 4 кв. 2025 не раскрыты (взяты чистые); открытия «Пятёрочки» с 4 кв. 2025 — «в современной
  концепции» (в 3 кв. 2025 это 628 из 644): закрытия этих кварталов могут быть занижены на ≈2–3 %.
* NL 2024–2025 гг. включает покупки 2023 г. («Тамерлан», «Виктория», магазины «Гроздь»/«Амба») и Vprok.ru (вне LFL) —
  d может быть завышена на сотые.
* Разложение m на трафик и чек — суждение (всё созревание отнесено к трафику).
