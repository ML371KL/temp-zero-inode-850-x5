# Факты X5: состав и поля (что читает ядро и выпуск)

Все файлы — JSON в UTF-8. Деньги — млрд ₽, площадь — тыс. м², акции — млн шт., доли —
доли единицы. Базис денег — до МСФО 16 (IAS 17). У КАЖДОГО числа — источник в поле
`src` рядом (файл первички › лист!ячейка или страница), либо `calc` (формула из других
фактов). Нераскрытое — `null`. Сверка с первичкой и хэши документов — `docs/FACTS.md`.

Общая форма значения: `{"v": 2480.513, "src": "financial_and_operating_results_q2_2026.xlsx › Profit and Loss!AA6 + AB6"}`.
Ядро читает `v`; тест связи проверяет, что у каждого числа `v` есть `src` или `calc`.
Нераскрытое — `{"v": null, "note": "…"}`: числа нет, источника не требуется; число без
`src`/`calc` — отказ ядра.

## accounting.json — отчётные полугодия (читает ядро)

```json
{
  "as_of": "2026-06-30",
  "periods": {
    "2025H1": {"revenue": {...}, "adj_ebitda": {...}, "lti": {...}, "ebitda_rep": {...}, "da": {...}, "capex": {...}},
    "2025H2": {...},
    "2026H1": {...}
  }
}
```

* `revenue` — выручка полугодия; `adj_ebitda` — скорр. EBITDA до МСФО 16 (без LTI и разовых);
  `lti` — расход LTI (положительное число); `ebitda_rep` — отчётная EBITDA до МСФО 16
  (= скорр. − LTI − разовые); `da` — D&A до МСФО 16 без обесценения, где раскрыто
  (иначе с обесценением и пометкой); `capex` — денежный capex (ОС + НМА), положительное число.
* Нужны минимум полугодия якоря и два предыдущих (для года к году и LTM).

## network.json — сеть (читает ядро)

```json
{
  "area_end": {"2023H2": {...}, "2024H1": {...}, ..., "2026H1": {...}},
  "area_end_est": {"2022H2": {...}, "2023H1": {...}},
  "net_added": {"2024H1": {...}, ...},
  "gross_opened_hist": {"2022H1": {...}, ..., "2026H1": {...}},
  "closed_area_est": {"2022H1": {...}, ..., "2026H1": {...}},
  "stores_end": {"2026H1": {...}},
  "by_format_2026H1": {"pyaterochka": {"area": ..., "stores": ...}, "perekrestok": ..., "chizhik": ...}
}
```

* `area_end` — торговая площадь трёх форматов на конец полугодия в СОПОСТАВИМОМ базисе
  (без дарксторов, «Красный Яр» и «Слата» внутри «Пятёрочки»), не короче 2023H2–2026H1.
* `area_end_est` — площадь на концы 2022H2 и 2023H1 в том же сопоставимом базисе — оценка листа
  сети (`evidence/network-revenue/common.py::network_history`; сборщик —
  `ops/tools/build_facts.py::network_history_est`, способ — в `calc`). Ядро начинает индекс
  эффективной площади с самого раннего полугодия, где площадь есть в `area_end` или
  `area_end_est` (сейчас 2022H2; `docs/MODEL.md` §4.1); отчётная площадь важнее оценки.
* `gross_opened_hist` — валовые открытия площади по полугодиям 2022H1–2026H1 (оценка, если не
  раскрыто: чистый прирост + закрытая площадь; 2022H1–2023H2 — оценка листа сети тем же правилом;
  способ — в `calc`). Ядро берёт открытия длины кривой созревания до начала индекса и дальше до якоря.
* `closed_area_est` — закрытая площадь по полугодиям 2022H1–2026H1 (оценка: закрытые магазины ×
  средняя площадь формата; способ — в `calc`); ядро берёт полугодия после начала индекса до якоря
  (закрытия с продуктивностью κ). Нет нужного полугодия — отказ сборки (`FactsError` с путём).

## balance.json — баланс якоря (читает ядро)

```json
{
  "as_of": "2026-06-30",
  "net_debt": {...},            // чистый долг компании до МСФО 16: общий долг (с лизингом) − денежные средства
  "total_debt": {...}, "cash": {...}, "leasing": {...},
  "dividends_payable": {...},   // объявленные и не выплаченные на дату якоря
  "nwc_op": {...},              // оборотный капитал по определению книги A-W1 (состав — docs/FACTS.md §5)
  "nwc": {...},                 // = nwc_op — его читает ядро (якорь оборотного капитала)
  "nwc_components": {...},      // слагаемые nwc_trade, nwc_magnit_like (справочно) и nwc_op
  "revenue_ltm": {...},
  "ebitda_rep_ltm": {...}, "adj_ebitda_ltm": {...},
  "lease_liabilities_ifrs16": {...},     // справочно, вне моста
  "credit_lines_unused": {...}
}
```

## bridge.json — строки моста EV → капитал (читает ядро; включение — `bridge.include` книги)

```json
{"as_of": "2026-06-30", "lines": [
  {"key": "accrued_interest", "label": "Начисленные проценты", "amount": {...}},
  {"key": "nci_put", "label": "Пут на неконтролирующую долю", "amount": {...}},
  {"key": "lti_liability", "label": "Обязательство LTI", "amount": {...}},
  {"key": "tax_provisions_net", "label": "Резервы по налоговым позициям (нетто)", "amount": {...}},
  {"key": "income_tax_net", "label": "Налог на прибыль к уплате − к возмещению (нетто)", "amount": {...}},  // знак любой
  {"key": "st_investments", "label": "Краткосрочные финансовые вложения", "amount": {...}},   // отрицательная
  {"key": "associates", "label": "Инвестиции в ассоциированные и СП", "amount": {...}}         // отрицательная
]}
```

Знак `amount` — как у требования: обязательство положительное, актив отрицательный.
Строка в файле ещё не требование: в мост идут только ключи `bridge.include` книги.

## shares.json (читает ядро)

`issued`, `treasury`, `treasury_at_subsidiaries`, `outstanding_mln` (в обращении на дату якоря),
`free_float_pct`, история продаж казначейского пакета. Ядро читает `outstanding_mln` (N) и
`treasury` (n — казначейские акции вместе с акциями у дочерних обществ; N + n = `issued`): цена =
[(V0 − D) + n·k·P_рынок/1000]·(1 − g)·1000/(N + n) (`docs/MODEL.md` §7.2).

## dividends.json — политика и реестр (читает ядро и выпуск)

```json
{
  "policy": {"target_leverage": [1.2, 1.4], "no_pay_above": 2.0, "frequency": "дважды в год", "src": "..."},
  "register": [
    {"id": "FY2025-final", "label": "Финальный за 2025 г.", "dps": 245, "amount": {...},
     "decided_on": "2026-06-26", "record_date": "2026-07-07", "ex_date": "2026-07-07",
     "pay_until": "2026-08-11", "status": "paid", "paid_share_on": {"2026-08-13": 0.761},
     "cash_in_company_at_facts_date": true, "src": "..."},
    {"id": "unclaimed-old", "dps": null, "status": "unclaimed", ...}
  ],
  "history": [...]                                   // выплаты 2018–2026 для витрины
}
```

`status` — на дату сбора фактов: `declared` — объявлен, выплата не началась; `paying` —
идёт выплата (срок `pay_until` не истёк); `paid` — срок выплаты истёк, выплаченная доля —
`paid_share_on`, невыплаченный остаток остаётся обязательством; `unclaimed` —
невостребованный остаток прошлых выплат (без DPS). Ядро поле не читает.

Требованием моста на дату оценки v становятся записи с `ex_date ≤ v` и
`cash_in_company_at_facts_date = true` (docs/MODEL.md §7.1). Смысл флага — «выплата
позже `facts_date`»: деньги под неё ещё в компании на дату якоря ИЛИ будут заработаны
после неё (уже сидят в перекате). Дивиденд за 9М2026 с отсечкой в январе 2027 г.
получит `true`. Их сумма на дату якоря
согласована с `balance.dividends_payable`.

## debt_register.json (читает выпуск)

Облигации (ISIN, выпуск, номинал в обращении на дату якоря и на дату сбора, купон:
фикс/флоатер, ставка/спред к КС, даты оферты и погашения), банковские кредиты (итог,
кратко-/долгосрочные), доля плавающих ставок, эффективная ставка, рейтинги, невыбранные
линии, график погашений по кварталам.

## history.json (читает выпуск и ядро)

Годы 2011–2025 и полугодия 2018H1–2026H1: выручка, рост, скорр. маржа, отчётная маржа,
capex/выручка, D&A/выручка, ЧД/EBITDA, LFL (продажи/трафик/чек), площадь, магазины, доли
форматов — для графиков «Расчёт» и «Деньги и долг». Ядро читает `halves[].revenue` и
`halves[].capex_pct` 2L полугодий до якоря (L — срок службы базы D&A книги; сейчас 2019H1–2025H2):
capex когорт, по которым выбывает база D&A якоря (`docs/MODEL.md` §4.5). Поля не переименовывать.

* `da_pct` — D&A **с обесценением** внеоборотных активов / выручка (строка databook);
  `da_excl_impairment_pct` — без обесценения (обесценение нетто по МСФО; раскрыто с 2023 г.,
  раньше — `null`). В `accounting.json › memo.da_pct` — D&A без обесценения.
* `other_investing_payments` — «Прочие платежи по инвестиционной деятельности» (ОДДС, млрд ₽,
  отток положительным); `finance_lease_receipts` — «Поступления от основной суммы чистых
  инвестиций в аренду» (ОДДС, млрд ₽). В `capex_pct` ряда (ОС + НМА), M&A и мост не входят; книга
  относит прочие платежи нетто строки 41 к поддерживающему capex прогноза (A-K1, `docs/DECISIONS.md`). Потоки идут с 4 кв.
  2023 г.; в databook 2026 до этого 0, в databook 2024 (годы ≤2020, полугодия ≤2022H2)
  строки нет — `null`.

## peers.json, brokers.json (читает выпуск)

Аналоги на одной базе (до МСФО 16, LTM на дату): тикер, акции в обращении, чистый долг,
EBITDA LTM, чистая прибыль LTM, дата отчёта — живая цена берётся конвейером. Цели
инвестдомов: брокер, дата, цель, рекомендация, источник.

## actuals.json (читает журнал)

Факты по целям журнала после отчётов: `{"target": "x5.adj_margin", "period": "2026H2",
"value": {"v": 0.061, "src": "файл первички › место"}, "reported_on": "2027-03-19"}`. `value` — узел
факта, как во всех файлах фактов (`src` или `calc`); число без узла журнал не принимает — отказ
сборки (`FactsError`). Одна запись на цель и полугодие. Вносятся человеком после публикации.
