# История изменений

Что изменилось в коде, книге, фактах и витрине и когда выложено. Новые записи — сверху; у выложенной записи — строка «**Выкладка:**». Решения с обоснованием — `docs/DECISIONS.md`; версии книги — теги `book-<версия>`. Числа в записях — на момент записи; текущие — `data/assumptions/results.json` и справочник.

## 1.0 — 28.09.2026: первая версия

- **Методика и контракт:** `docs/MODEL.md` — метод Магнита 850oa, приспособленный к X5 (отличия — §15); контракт выпуска `x5-v1` — `docs/PAYLOAD.md`.
- **Ядро** `model/`: книга с закрытой схемой, факты с источником у каждого числа, проход клетки по полугодиям 2026H2–2036H2 и терминал, сетка 36 клеток, правило A-P2u, слои и точка, мост и внутренняя стоимость, полоса по суждениям книги, обратный DCF, «что даст отчёт», журнал прогнозов, выпуск с защитой заголовка; в коде нет чисел книги и фактов.
- **Контрольная модель** `tests/independent_model.py` — по тексту методики, книги и фактов без доступа к ядру; совпадает с ядром в допусках на книге и на сценариях с выключенными книгой ветками (`docs/CONTROL-MODEL.md`).
- **Факты** `data/facts/` на якорь 30.06.2026 (2026H1) из первички, у каждого числа источник (`docs/FACTS.md`); календарь событий `data/calendar.json`.
- **Книга 1.0** собрана из четырёх областей — сеть и выручка; маржа и режимы; capex, оборотный капитал, касса, налог; финансирование, мост, оценка, гейты — с доказательными листами `data/assumptions/evidence/`. Миры ставок, веса слоёв и λ — книги Магнита 1.6 (кривая 18.09.2026). Проценты считаются от валового долга без двойного счёта операционной кассы (`docs/MODEL.md` §4.9). Сработавший гейт `ev_ebitda` объяснён (`data/assumptions/gate_explanations.yaml`).
- **Числа книги 1.0** (дата оценки 25.09.2026, рынок 1 808,5 ₽): медиана 3 750 ₽ (точно 3 736), полоса 80 % 2 900–4 600 ₽, 50 % 3 250–4 200 ₽, точка 3 850 ₽ (3 863), P(ниже рынка) 0,05 %, EV медианы против V\* +55,7 %.
- **Живые входы** `indicators/`: MOEX ISS (цена, история закрытий, аналоги, кривая ОФЗ, облигации), ключевая ставка ЦБ.
- **Конвейер** GitHub Actions `pipeline.yml` — по будням, при push кода, книги и фактов в `main`, вручную; публикация в орфан-ветку `data`, сверка через боевую дверь, keepalive расписания. CI `ci.yml`. В такте — только тесты числа и контракта; полная полоса, сценарии контрольной модели, публикация через git и прогон «в будущем» — в CI.
- **Витрина** — шесть экранов, тема 20:00–07:00, CSP с хэшем скрипта темы; дверь данных `/api/model` на raw GitHub с запасной копией в кэше края; Pages-проект `tzi-850-x5`.
- **Документы:** `README.md`, справочник `docs/MANUAL.md`, `docs/DASHBOARD.md`, `docs/INDICATORS.md`, `data/assumptions/README.md`, `docs/DECISIONS.md`; числа результатов книги — метками `ops/tools/render_numbers.py`.

**Выкладка:** 28.09.2026. Код и выпуск — `meta.engine_commit` и `meta.payload_sha256` выпуска на `/api/model` (команда — `docs/MANUAL.md`, раздел 10.1); витрина — выкладка `wrangler` с ноутбука (раздел 10.5).
